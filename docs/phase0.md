## Deviation 3 — spec form (`@[progress]` and `∃ r, f args = ok r ∧ Post r`)

In Aeneas `5d08da45`:

- `progress` is a deprecated alias of `step`; `@[progress]` is a deprecated
  alias of `@[step]` (emits a warning, same database).
- The `step` attribute **rejects** both conclusion shapes mandated by
  IMPLEMENTATION.md §1: `∃ r, f args = ok r ∧ P r` fails with
  "Exists is not a supported spec statement name" and `f args = ok e` with
  "Eq is not a supported spec statement name". The only accepted statements
  are the registered ones, `Aeneas.Std.WP.spec` (notation `f args ⦃ r => P r ⦄`)
  and `Aeneas.Std.WP.dspec` (partial correctness, `⦄div`).
- `WP.spec x p ↔ ∃ y, x = ok y ∧ p y` (`Aeneas.Std.WP.spec_equiv_exists`).

So the fixed spec form becomes, equivalently:

```lean
@[step] theorem <f>_spec (binders) (hyps) : <f> <args> ⦃ r => <Post r> ⦄ := by sorry
-- exact flavour:
@[step] theorem <f>_spec (binders) (hyps) : <f> <args> ⦃ r => r = <expr> ⦄ := by sorry
```

Only `WP.spec` is permitted (never `dspec`). The closed Prop is
`∀ binders, hyps → WP.spec (f args) P`, and `lean_tools` supplies a
`Decidable (WP.spec x p)` instance from the `∃` characterisation.
Every rule in IMPLEMENTATION.md that says `progress` reads `step`
(`step`, `step*`, `@[step]`).

## Deviation 4 — `divergent def`

This Aeneas emits no `divergent def`. Non-structural recursion is emitted as
`def … partial_fixpoint` (74 definitions in `corpus/`); in the environment
such a constant's value references `Lean.Order.fix` (directly, or through the
`<name>.mutual` packaging constant for `mutual` blocks). `is_divergent` is
defined as exactly that. Loops are emitted either as the `Aeneas.Std.loop`
combinator (`@[rust_loop] def f_loop` + `@[rust_loop_body] def f_loop.body`,
171 of them) or, for some shapes, as recursive `f_loop` functions with
`partial_fixpoint` (those units are skipped as divergent, per §1).

## Deviation 5 — generics

Aeneas emits type parameters as *implicit* binders (`{T : Type}`), and trait
instances as *explicit* structure-typed binders (`(OrdInst : avl.Ord T)`).
`is_generic` is therefore: any binder whose type is a `Sort`, any
instance-implicit binder, or any binder whose type's head is a crate-emitted
trait structure.

`Corpus/Types.lean`, `Corpus/Funs.lean` (and `Corpus/FunsExternal*.lean` if

`namespace Corpus`, e.g. `Corpus.adt_borrows.array_shared_borrow`. Module
names: `Corpus.Types`, `Corpus.Funs`; root module `Corpus` is generated by
`check.sh`.
